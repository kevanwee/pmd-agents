# PMD Agents 0.5.1 — release candidate

Publication pending resolution of artwork and branding permissions.

PMD Agents displays local coding-agent activity in an Explorer widget and, on
Windows x64, an always-on-top companion when its owning VS Code window is
minimized. The full guild includes the activity journal, connections and team
selection. This first release candidate includes the 0.5.0 widget functionality.

- First-run installation, privacy, troubleshooting, update and removal guides.
- Proprietary original-code licence permitting installation and use; third-party
  material retains separate terms.
- Version-derived packaging, strict file inventory and SHA-256 checksum.

Requires local Windows x64, VS Code 1.109+ and Microsoft Edge WebView2 Runtime.
The VSIX contains no game artwork. Choose a separate compatible pack that you are
permitted to use; without it the animated scene is unavailable. Python is needed
only for the existing source-based starter-pack importer, not VSIX installation.

Live Codex transcript and terminal observation have been tested locally. Live
native Claude coverage and remote/non-Windows hosts remain unverified. Local
transcript observation is enabled by default in trusted workspaces and can be
disabled in settings. Initial desktop-window binding needs a visible status bar.

Install through **Extensions: Install from VSIX**, then reload all open windows.
Compare `Get-FileHash .\pmd-agents-0.5.1.vsix -Algorithm SHA256` with the published
`.sha256` file. See the [setup guide](https://github.com/kevanwee/pmd-agents/blob/main/docs/SETUP.md).
