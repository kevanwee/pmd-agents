# PMD Agents 0.7.0

13 October 2026 · Windows x64. Includes the unreleased 0.5.3 and 0.6.0 changes.

- **Varied spawns and favorites.** New teammates are no longer always Eevee or
  Riolu. The guild reviews who is already on the team and spawns the first
  favorite nobody is using, then a random species no active teammate has. Add
  favorites from any Pokémon's menu in the storage system and order them in its
  new **Favorites** tab; they are saved in `pmdAgents.favorites`, and any missing
  from your pack import in the background.
- **Every Friend Area.** The Friend area list grows from 11 maps to 73: all 57
  Red Rescue Team Friend Areas, with native palette and tile animation and floors
  from the game's collision data, plus 16 Explorers of Sky areas when
  skytemple-files is installed. Refresh an existing pack's maps with
  `npm run import:scenery -- --output "C:/path/to/your/pack"` from the source
  checkout. Maps build only when shown.
- **Desktop widget.** It opens at a configurable size every time
  (`pmdAgents.desktopWidgetWidth` / `desktopWidgetHeight`, remembering only its
  position), with Appletun's sprite as its window icon.

Install the VSIX in each desired profile and reload already-open windows.
Compare `Get-FileHash .\pmd-agents-0.7.0.vsix -Algorithm SHA256` with its checksum.
See the [setup guide](https://github.com/kevanwee/pmd-agents/blob/v0.7.0/docs/SETUP.md).

Local Windows x64, VS Code 1.109+ and WebView2 are required for the desktop
companion. Game artwork remains separate. This unofficial fan release and its
original-code licence do not grant third-party artwork or branding rights.

Automatic matching needs the chat's project folder. Overlapping windows pause
unbound automatic claims; explicit window-bound hooks and terminals still work.
Live Claude CLI turns and live Codex transcripts were verified; full native Claude
UI, approval and child-agent flows remain unverified. Remote and non-Windows hosts
remain untested.
