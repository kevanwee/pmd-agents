# PMD Agents 0.5.2

12 October 2026 · Windows x64.

- Fresh trusted VS Code windows now reveal the Explorer widget automatically,
  without taking keyboard focus. `pmdAgents.autoShowWidget` controls this.
- Support verified Claude transcript formats 2.1.77, 2.1.295 and 2.1.296 alongside
  2.1.289/2.1.292. Hook sessions gain workspace membership as matching transcripts
  arrive. Available-session cards explain why automatic connection is waiting.
- Import and cycle each species' available Attack, Shoot, Strike, QuickStrike,
  MultiStrike and SpAttack sheets, retaining native frames, anchors and hit timing.
  Aliases of the same sheet play once. Training starts from the beginning after
  travel or attention rather than resuming midway through an attack.
- Existing packs remain compatible. Upgrade their combat sheets with
  `npm run import:training -- --output "C:/path/to/your/pack"` from the source
  checkout, then reload VS Code. New species imports include them automatically.

Install the VSIX in each desired profile and reload already-open windows.
Compare `Get-FileHash .\pmd-agents-0.5.2.vsix -Algorithm SHA256` with its checksum.
See the [setup guide](https://github.com/kevanwee/pmd-agents/blob/v0.5.2/docs/SETUP.md).

Local Windows x64, VS Code 1.109+ and WebView2 are required for the desktop
companion. Game artwork remains separate. This unofficial fan release and its
original-code licence do not grant third-party artwork or branding rights.

Automatic matching needs the chat's project folder. Overlapping windows pause
unbound automatic claims; explicit window-bound hooks and terminals still work.
Removed sessions remain excluded until reattached. Live Claude CLI turns and
live Codex transcripts were verified; full native Claude UI, approval and child
agent flows remain unverified. Remote and non-Windows hosts remain untested.
