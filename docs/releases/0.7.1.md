# PMD Agents 0.7.1

13 October 2026 · Windows x64. A patch to 0.7.0's favorites.

- The **Favorites** tab is now a grid of equal-size icons numbered by priority,
  fitting dozens of favorites without scroll bars. Drag a tile (or press
  Alt+arrow keys) to reorder; click it to switch its form or remove it.
- Clicking anywhere outside an open Pokémon menu, or the favorite editor, closes it.

Everything in [0.7.0](https://github.com/kevanwee/pmd-agents/releases/tag/v0.7.0)
still applies: varied spawns from your favorites, every Friend Area, and the
configurable desktop widget.

Install the VSIX in each desired profile and reload already-open windows.
Compare `Get-FileHash .\pmd-agents-0.7.1.vsix -Algorithm SHA256` with its checksum.
See the [setup guide](https://github.com/kevanwee/pmd-agents/blob/v0.7.1/docs/SETUP.md).

Local Windows x64, VS Code 1.109+ and WebView2 are required for the desktop
companion. Game artwork remains separate. This unofficial fan release and its
original-code licence do not grant third-party artwork or branding rights.
