# PMD Agents

A planned Pokémon Mystery Dungeon companion for agents working in a VS Code window.

**Status: planning only — 9 October 2026.** No extension, hooks, or runtime have been installed by this project. The working name is `pmd-agents`.

Read the [full product and engineering plan](docs/PLAN.md), [source review and archive receipt](docs/RESEARCH.md), and [attribution plan](docs/ATTRIBUTION.md).

The predecessor, [The Office](https://github.com/kevanwee/theoffice), was archived on GitHub at the owner's request. This is a separate project; Voracity supplies visual references and candidate assets.

Inspired by [Pixel Agents](https://github.com/pixel-agents-hq/pixel-agents), by Pablo De Lucca and contributors.
